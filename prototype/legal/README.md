# Approved footer documents

Place the company-approved PDFs under `prototype/public/legal/` when they are ready for public distribution. Set `SEAMLESS_PRIVACY_PDF` and `SEAMLESS_TERMS_PDF` to their filenames before running the prototype build. The footer lists only configured files that exist. The links open the PDFs and allow downloading through the browser.

Keep the archive and final site private until the publication gate is approved. Vite copies all files in its public directory to the build, so place only approved public files there.
